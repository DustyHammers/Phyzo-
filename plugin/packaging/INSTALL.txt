Phyzo for macOS (Apple Silicon): installing
===========================================

The full step-by-step guide is docs/INSTALL_MAC.md in the repository.

1. Quit REAPER.

2. Copy the plugins (replace older copies if asked):
     Phyzo.vst3       ->  ~/Library/Audio/Plug-Ins/VST3/
     Phyzo.component  ->  ~/Library/Audio/Plug-Ins/Components/
   In Finder: menu Go > Go to Folder..., paste the folder path, press Return.
   Create the VST3 or Components folder if it does not exist.

3. Clear the macOS quarantine flag. Open Terminal and paste this one line, then press Return:

     xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Phyzo.vst3 ~/Library/Audio/Plug-Ins/Components/Phyzo.component

4. Let macOS re-read its Audio Unit list (paste in Terminal, press Return; "No matching processes" is fine):

     killall -9 AudioComponentRegistrar

5. Start REAPER. If Phyzo is not listed, open Preferences > Plug-ins > VST and click "Re-scan".

The plugin is ad-hoc signed (not notarised by Apple). That is why step 3 is needed.
